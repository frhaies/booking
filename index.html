最新版「雙向同步」Apps Script 程式碼（支援寫入＋自動更新網頁）
  1. 前往 script.google.com，打開你原本的專案（或按「新增專案」）。
  2. 全選並覆蓋貼上剛複製的 Apps Script 程式碼（切勿貼入 HTML 網頁內容），按上方磁碟圖示儲存。
  3. 按右上角「部署」→「新增部署作業」→ 類型選「網頁應用程式」→ 執行身分選「我」→ 誰可以存取務必選「所有人」→ 按「部署」並完成授權。
  4. 複製產生的「網頁應用程式網址（結尾為 /exec）」，貼到上方第 1 格 → 按「測試連線」確認出現綠色成功訊息 → 按「儲存設定」。
  5. 重要：儲存後，必須再點「匯出網頁 / 取得網址」重新下載 index.html 並覆蓋上傳到 GitHub，客人的網址才會生效！

100% 成功覆蓋 GitHub 的方法（避免出現 index (1).html）：

1. 點擊上方「一鍵複製完整網頁程式碼」（已自動內建你的 Google 日曆同步網址）。

2. 打開你的 GitHub 專案 → 點開原本的 index.html → 點右上角鉛筆圖示（Edit this file）。

3. 在編輯框內按 Ctrl+A 全選刪除 → 按 Ctrl+V 貼上 → 按右上角綠色「Commit changes」儲存。

4. 等待 1–2 分鐘後重新整理網址，紅色提醒條消失即代表已成功寫入！
