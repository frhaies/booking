如何取得免費 Apps Script 網址？（4 步驟）
  1. 前往 script.google.com 並點擊左上角「新增專案」。
  2. 刪除原本內容，貼上剛複製的程式碼並按儲存。
  3. 按右上角「部署」→「新增部署作業」→ 類型選「網頁應用程式」→「誰可以存取」選「所有人」→ 按「部署」並授權。
  4. 複製產生的「網頁應用程式網址」，貼到上方第 1 格按儲存即可！

GitHub 上傳更新步驟：

1. 點擊上方綠色按鈕下載 index.html（確保檔名完全小寫，不可為 index (1).html）。

2. 進入你的 GitHub 專案（Public）→ 點「Add file」→「Upload files」→ 拖曳上傳覆蓋舊檔並按「Commit changes」。

3. 確認「Settings → Pages」的 Branch 為 main 且資料夾為 /(root)，等約 1–2 分鐘即可生效。
